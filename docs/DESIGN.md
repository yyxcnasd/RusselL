# 设计语言

公理板只有一屏：纸面棋盘 + 贴纸模块 + 电路导线。这份规范约束颜色角色、字体、形状、
组件状态与文案记法，目标是让所有界面看起来是同一套系统，而不是一张张拼起来的图。

实现都落在 `src/simple.css` 的 token 与组件规则里；改设计时先改 token，再改组件。

## 1. 颜色角色

| Token | 角色 | 用在哪里 |
| --- | --- | --- |
| `--bg` / `--board` / `--card` | 三级纸面（页 / 棋盘 / 卡片） | 应用背景、棋盘、节点与浮层 |
| `--soft` / `--soft-hover` | 平涂行（面板内部） | 帮助卡片、成就卡、关卡格、存档按钮 |
| `--ink` / `--muted` | 正文 / 辅助文字 | 标题与状态用 ink，说明与计数用 muted |
| `--accent` | 铜橙 = 注意力 | 目标焊盘、当前位置、进度、焦点环、星标、原子端口 |
| `--green` | 成功 | 通关勾、目标完成、可用校验钮、效率条 |
| `--red` | 错误 | 错误节点/导线、失败提示 |
| `--port-formula` / `--port-atom` / `--port-assert` | 端口与导线角色 | 蓝=公式，铜橙=原子，墨=断言 |
| `--stamp-bg` / `--stamp-fg` / `--stamp-shadow` | 反相印章 | 主操作按钮、当前关卡、选中芯片（浅色墨底纸字，暗色纸底墨字） |

规则：**accent 不做主操作**。主操作统一用反相印章；accent 只负责“看这里”。
端口/导线颜色按角色固定，不随主题改成另一套语义。

## 2. 字体与字号

| 用途 | 字体 | 字号 / 字重 |
| --- | --- | --- |
| 公式、变量、数学符号 | STIX Two Text（`--math`，变量斜体） | 节点 21px / 目标 clamp(20–30) / 面板内 13–19 |
| 界面文字 | IBM Plex Sans + 系统中文栈（`--font`） | 标题 18、正文 15、辅助 13、元信息 12、计数 11–12 |
| 模块代号 | IBM Plex Sans 600 | 节点 14、托盘 16、浮条 15 |

约定：**代表公式的字母一律 STIX 斜体，代表模块/代号的字母一律 Plex**。
中文不落到不可控的默认字体：`--font` 里显式带 PingFang / 思源黑 / 微软雅黑。

## 3. 形状、描边与投影

- 圆角只有四档：`--radius-sm:12`（芯片/格子/小按钮）、`--radius:16`（卡片/节点/托盘）、
  `--radius-lg:22`（浮层/提示窗）、`--radius-sheet:26`（面板）；胶囊用 `--radius-pill`。
- 贴纸描边 1.5px（`--line`）；目标焊盘 2px 虚线；锁定关卡 1px 虚线。
- 投影只有一套“贴纸”：`--sticker` = `0 3px 0 var(--key)`；hover 用
  `--sticker-hover`（4px），active 用 `--sticker-press`（1px）。浮层用柔和投影
  （`--pop-shadow` / `--sheet-shadow` / `--ghost-shadow`）。不要再引入新的硬投影颜色。
- 图标线宽 `--icon-stroke:1.75`，尺寸只取 16 / 20 / 24（大状态勾 34）。

## 4. 组件状态

- **贴纸组件**（可拖拽/可点击）：节点、托盘 tile、顶栏按钮。hover 上浮 1px + 4px 投影，
  active 下沉 1–2px + 1px 投影。
- **平涂行**（面板内部）：帮助卡、成就卡、存档按钮、步骤块。soft 底、无描边、hover 变
  `soft-hover`；白贴纸只留给棋盘上的模块。
- **关卡格** 只有四种：默认（soft）/ 已通关（accent-soft）/ 当前（反相印章）/ 锁定
  （透明 + 虚线边 + 降透明）。挑战段由分带标题与星形图标表达，格子上不再重复星标。
- **面板 chrome**：每个面板顶部是 `.sheet-head`（`h2` 标题 + 右对齐 meta），右上角统一
  关闭按钮；面板打开时背景 `inert`、焦点陷阱、Esc 关闭并归还焦点。
- **过渡**：120ms 按压、180ms 淡入淡出、0.45s 入场；`prefers-reduced-motion` 下停掉
  呼吸/脉冲/彩带。

## 5. 文案与记法

- 对象语言：`→` 蕴含、`↔` 等价；规则层面：`⇒` 规则产出、`⇄` 定义双向置换、`↦` 代入。
  多前提用逗号，如 `A, A→B ⇒ B`。
- 变量一律单字母斜体（P、Q、x、t）；模块代号用 S / M / D / HS / ∀I / ∀E / ∃I / ∃E。
- 状态词固定：校验（顶栏按钮）、下一关、选关、通电（首个成就）、已通关、未解锁。
- 带文字优于纯图标：帮助三步写成“取模块 / 接线 / 校验”，规则卡写明前提与结论。

## 6. 响应式

- ≤700px：顶栏两行（关卡号 + 工具组 / 目标公式整行）；元件盘横向滚动并用 12px 渐隐提示；
  面板全宽、成就 3 列、关卡 5 列。
- ≤380px：目标公式 12.5px 起、帮助卡单列、`下一关` 按钮撑满。
- 触屏：棋盘支持双指缩放；端口命中区用 `::after` 扩到 38px 以上。

## 7. 不要动的东西

1. 米色纸面 + 贴纸描边 + 硬投影的整体材质；
2. 电路隐喻（端口圆点、开口导线、圆角焊盘、⊢ 目标焊盘）；
3. 公式 STIX / 界面 Plex 的双字体分工；
4. 顶栏三栏栅格与让 toast 自动下移的 grid 行；
5. 克制的动效与铜橙 focus-visible。
