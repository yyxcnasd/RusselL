## 3. 设计原则（照 set.mm 的做法）

1. **一条阶梯，不跳级**：每章普通关是一条依赖链，第 k 关只引用第 k 关之前的关卡。这就是
   set.mm 的做法——`id → a1i → mpd → syl → …` 每步只多一点点。玩家通关路径即课程路径。
2. **证明即组合**：每关参考解 = 少量 `S`/`M` + 前面引理的 `theorem` 引用 + 公理/规则实例。
   普通关因此能压到 5–21 模块，而不是从 A1–A3 硬推上百步。
3. **困难关 = 两三条引理的合流**：用本章（及前章）的引理做更长的推导；模块数按 20 → 200
   递增。超过 200 就**拆**：把中间结论抽成新的早一关（多数自然落进普通关区间）。
4. **每章有明确主题**（见 §4），目标公式必须是该主题的定理，而不是「给公式加 ∀」。
5. **D 仍是唯一定义入口**：`∧/∨/↔` 的规则关用原始语言证明，末尾 `def-contract` 折回表面语法。

## 4. 四章课程大纲

### 第Ⅰ章 命题演算（16 普通 + 18 困难）

普通（引理阶梯，括号内是预期模块数）：

1. 同一律 `P→P` (5)
2. 蕴涵自应用 `P→((P→Q)→Q)` (现有 *03, 19)
3. 前件交换 `(P→Q)→((R→P)→(R→Q))` (*04, 18)
4. 空真 `¬P→(P→Q)` (*14, 18)
5. 双重否定引入 `P→¬¬P` (阶梯重排后 ~13)
6. 双重否定消去 `¬¬P→P` (~15)
7. 逆否 `(P→Q)→(¬Q→¬P)` (~20，引用 5/6)
8. 合取引入 `P→(Q→(P∧Q))` (~10，引用 2/4)
9. 合取消去左 `(P∧Q)→P` (~8)
10. 合取消去右 `(P∧Q)→Q` (~8)
11. 析取引入左 `P→(P∨Q)` (~10)
12. 析取引入右 `Q→(P∨Q)` (~6)
13. 等值引入 `(P→Q)→((Q→P)→(P↔Q))` (~10)
14. 等值消去左 `(P↔Q)→(P→Q)` (~6)
15. 等值消去右 `(P↔Q)→(Q→P)` (~6)
16. 排中律 `P∨¬P`（= `¬P→¬P`，~6；作为经典推理的起点）

困难（18 关，按模块数递增，代表目标）：

- 析取消去 `(P∨Q)→((P→R)→((Q→R)→R))`（分情况，150–200）
- 反证 `(¬P→Q)→((¬P→¬Q)→P)`
- 皮尔士律 `((P→Q)→P)→P`
- 德摩根两条 `¬(P∧Q)→(¬P∨¬Q)`、`¬(P∨Q)→(¬P∧¬Q)`
- 合取/析取的结合、分配 `(P∧(Q∨R))→((P∧Q)∨(P∧R))`
- `¬(P→Q)→(P∧¬Q)`、`(P∧¬Q)→¬(P→Q)`
- 三段论链 `(P→Q)→((Q→R)→((R→S)→(P→S)))`
- 等值传递/自反：`(P↔Q)→(Q↔P)`、`(P↔Q)→((Q↔R)→(P↔R))`
- 析取三段论 `(P∨Q)→(¬P→Q)`
- 全章综合：`((P∨Q)→R)↔((P→R)∧(Q→R))`

### 第Ⅱ章 谓词推理（12 普通 + 22 困难）

先做一处语言扩展：`pred` 模块支持**二元谓词** `F(x,y)`（term.js 早已支持读写，只差 modules.js 的
arity 配置与端口复用），这样谓词章才能出现真正的「关系」推理，而不是一堆 `F(x)` 套 ∀。

普通（引理阶梯）：

1. 全称例化 `∀x F(x)→F(y)`
2. 全称分配 `∀x(F(x)→G(x))→(∀xF(x)→∀xG(x))`
3. 全称合取 `∀x(F(x)∧G(x))→(∀xF(x)∧∀xG(x))`
4. 合取全称 `(∀xF(x)∧∀xG(x))→∀x(F(x)∧G(x))`
5. 全称前置 `∀x(P→G(x))→(P→∀xG(x))`（19.21，x 不在 P 中）
6. 存在推广 `F(y)→∃xF(x)`（∃I* 的实例化用法）
7. 存在分配 `∀x(F(x)→G(x))→(∃xF(x)→∃xG(x))`（exim，用 ∃E）
8. 否定存在 `¬∃xF(x)→∀x¬F(x)`
9. 存在否定 `∃x¬F(x)→¬∀xF(x)`
10. 量词换序 `∀x∀yF(x,y)→∀y∀xF(x,y)`（ax-7；二元谓词）
11. 存在前置 `∃x(P→G(x))→(P→∃xG(x))`（x 不在 P 中）
12. 全称/存在对偶 `¬∀xF(x)→∃x¬F(x)`

困难（22 关，20→200 递增）：

- `∀x(F(x)↔G(x))→(∀xF(x)↔∀xG(x))`（19.20）
- `∃x(F(x)∨G(x))↔(∃xF(x)∨∃xG(x))`
- `∀x(F(x)∨P)↔(∀xF(x)∨P)`（19.31）
- `∃x∀yF(x,y)→∀y∃xF(x,y)`
- `∀x(F(x)→G(x))→(∀xF(x)→∃xG(x))`
- 量词链：`∀x∀y(F(x,y)→G(x,y))→(∀x∀yF(x,y)→∀x∀yG(x,y))`
- 前束化两条（把 ∀ 提到 ∧/∨ 外）
- `∃x(F(x)∧P)↔(∃xF(x)∧P)`（x 不在 P）
- `∀x∃yF(x,y)↔∃y∀xF(x,y)`？——**不做**：它在空域/交换性上不成立，不能作为定理（§6 风险）

### 第Ⅲ章 等值推理（12 普通 + 22 困难）

普通：

1. 自反 `x=x`（=I）
2. 对称 `x=y→y=x`
3. 传递 `x=y→(y=z→x=z)`
4. 代入（原子）`x=y→(F(x)→F(y))`（=L）
5. 反向代入 `x=y→(F(y)→F(x))`
6. 等式替换 `x=y→(x=z↔y=z)`
7. 归属左侧 `x=y→(x∈z↔y∈z)`
8. 归属右侧 `x=y→(z∈x↔z∈y)`
9. 双向等值 `x=y→(F(x)↔F(y))`
10. 全称自等 `∀x x=x`
11. 等式链三段 `x=y→(y=z→(z=w→x=w))`
12. 等号消去 `∀z(z=x↔z=y)→x=y`（不需要 DV 的版本）

困难（22 关）：

- `x=y→∀z(z∈x↔z∈y)`（外延方向）
- `∀x∀y(x=y↔∀z(z∈x↔z∈y))`（外延 ⇄ 等号，集合章铺路）
- `x=y→(x∈z↔y∈z)` 的 ∀ 闭包、`x=y→(z∈x↔z∈y)` 的 ∀ 闭包
- 同余推广：`x=y→((F(x)→G(x))↔(F(y)→G(y)))`
- 等号替换链（3–4 项）
- `∃x x=y`、`∃x∀y(x=y↔y=z)`（唯一性铺垫）
- `x=y→∀z z=x→∀z z=y` 等

### 第Ⅳ章 集合论（12 普通 + 22 困难）

普通（用 EXT / EMPTY / PAIR / UNION 四条集合公理，目标全部是「有内容的集合论陈述」）：

1. 外延公理（EXT 实例）
2. 空集存在 `∃z∀x¬(x∈z)`
3. 空集唯一 `∀x∀y((∀z¬z∈x∧∀z¬z∈y)→x=y)`
4. 配对存在 `∃u∀z(z∈u↔(z=x∨z=y))`
5. 配对唯一 `∀x∀y∃!u…` 的 ∀ 形式（用 EXT）
6. 并集存在 `∃y∀z(z∈y↔∃u(z∈u∧u∈x))`
7. 并集唯一
8. 成员关系替换 `x=y→(z∈x↔z∈y)`（与第Ⅲ章接上）
9. 配对成员律 `z∈u∧u={x,y}→(z=x∨z=y)` 的纯公式版
10. 并集成员律
11. 并集吸收 `∃u(x∈u∧y∈u)`（配对+并集）
12. 外延判别 `(∀z(z∈x↔z∈y))→x=y` 的 ∀ 闭包

困难（22 关）：

- 从配对公理到「无序对唯一」：`∃u∀z(z∈u↔(z=x∨z=y))` 与 `∃u∀z(z∈u↔(z=y∨z=x))` 推出 `u` 相等
- `x=y→(x∈z↔y∈z)` 与 EXT 合流：`x=y↔∀z(z∈x↔z∈y)`（完整定理）
- 幂等/交换/结合式的集合恒等式（用 EXT + 成员律证明 `x∪y=y∪x` 等，若语言允许）
- `∀x∀y∃u(x∈u∧y∈u)`、`∀x∃u(x∈u)`（空集以外的存在性）
- 成员关系无三循环？——**不做**：我们的公理里没有正则性，不能声称
- 综合：`x=y→∀z(z∈x↔z∈y)` 与 EXT 反向组合成完整外延判别

## 6. 风险与限制（先说清楚）

1. **谓词章的真实证明是最大工作量**：我们的语言没有 `⊥`、没有类项/函数符号，只有一元（扩展后
   二元）谓词 + ∈ + =。空域问题导致 `∀xφ→∃xφ` 这类不能做定理（空域下不成立），必须避开。
2. **DV 条件**：引擎没有 Metamath 的 `$d` 机制，谓词引理必须像现有素材那样**用字母差异显式表达**
   （如 `∀x(F(y)→G(x))→(F(y)→∀xG(x))` 里 x≠y）。从 set.mm 搬证明时必须逐条检查 else 会不严谨。
3. **表达式长度**：set.mm 里很多漂亮定理公式很长（>36 token），普通关只能选短的；长公式的定理
   放困难关（≤60）。仍超长的换成「前提形式」或拆成两步。
4. **拆分上限**：若某关拆分后仍 >200（例如需要从 A1–A3 硬证的经典定理），则换更弱的目标，
   不硬塞。
5. **存档兼容**：关卡 code 会整体重排（旧的 Ⅰ-11…Ⅰ-19 引理带消失）。旧存档按 code 存电路，
   新关卡下可能对不上——按「关卡重置」处理并在 README 注明；如需要可加一次 id 映射。
6. **工作量**：预计 152 关全部重写。序：机制 → Ⅰ 章 → Ⅲ 章 → Ⅳ 章 → Ⅱ 章（最难放后面，
   有回退空间）→ 文档/验收。

1. **模块数主要由公式构造节点决定，不是证明步数**。set.mm 的 `id` 在棋盘上是 13 个元件，
   `pm3.2im`（∧I 的原始形式）100 个，`simplim` 127 个，`pm2.6`（分情况）287 个：
   因为 set.mm 的证明大量依赖推理式引理（mpd/a1i/syl/con3d…），内联它们会重复构造公式。
   → 普通关 5–21 的名额**必须靠手写的紧凑证明**（或旧 legacy 小证明 11/8/19/18/18 个元件），
   不能指望 set.mm 导入关直接落进 22 以下。
2. 因此第Ⅰ章的结构改为：
   - 普通关 10 个 = 紧凑基础阶梯：legacy *01 (11)、*02 (8)、*03 (19)、*04 (18)、*14 (18)
     + 手写 前件重排 / 蕴涵传递 / 前件收缩 / 合取引入 / 等值引入（各 10–20 模块）；
   - 困难关 24 个 = 导入的 set.mm 引理（按模块数递增、依赖闭合、≤200；>200 的 4 个先剔除，
     后续用拆分工具把中间断言提成更早的关）。
3. `∧/∨/↔` 规则关的目标（表面语法）需要 `def-contract` 收尾；它们引用导入关
   （`pm3.2im` / `simplim` / `simprim` / `pm2.24`），排在那些导入关之后，因此会落在困难关前段。
4. 需要在 M1 补的能力：把 legacy 预编译电路（已验证）作为「circuit 关卡」接入新编译器，
   这样普通关可以直接用 *01/*02/*03/*04/*14 的电路（不必从 set.mm 重新翻译）。
