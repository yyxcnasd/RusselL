# 等词层 / Equality

谓词演算之后，游戏增加了第 Ⅷ 章「等词」。这一层对应《数学原理》的同一性理论（*13）以及 Metamath set.mm 的等词公理，但只取实现关卡所需的最小核心。

## 表示

`x = y` 被编码为二元谓词节点：

```js
{ k: 'pred', name: '=', args: [{k:'var',name:'x'}, {k:'var',name:'y'}] }
```

这样不需要新增 AST 节点类型，等词可以直接复用现有的自由变元、替换、释义展开、稳定 key 和渲染逻辑。

## 公理

| id | PM 编号 | 公式 |
| --- | --- | --- |
| EQ1 | *13.1 | x = x |
| EQ2 | *13.2 | x = y → y = x |
| EQ3 | *13.3 | (x = y ∧ y = z) → x = z |
| EQ4 | *13.4 | x = y → (F(x) → F(y)) |
| EQ5 | *13.5 | x = y → (F(y) → F(x)) |

它们作为 `pred-axiom` 模块出现，不冒充从谓词规则推导出的定理。

## 关卡里的推理

等词关卡不是把 EQ1–EQ5 直接接到目标，而是继续使用量词规则：

- 先用 `∀I`（全称推广）把带自由变元的等词公理闭包成 `∀x∀y…`；
- 再用 `∀E`（全称例化）把闭包式实例到 `a`、`b`、`c`；
- 得到 `a=a`、`a=b→b=a`、`(a=b∧b=c)→a=c`、`a=b→(F(a)→F(b))` 等目标；
- `∃I` 用于 `∃x x=x`。

因此每关至少包含一条公理加一到数条量词规则，而不是单个模块直接交板。

## 来源

- Whitehead & Russell, *Principia Mathematica*, *13（同一性）。
- Metamath set.mm 的等词公理体系可作为后续扩展参考。
