# 等词层（第 Ⅲ 章）

等词层使用 set.mm 的等词公理。等词和前两章一样是**同一个 AST 上的谓词**：

```js
{ k: 'pred', name: '=', args: [{k:'var',name:'x'}, {k:'var',name:'y'}] }
{ k: 'pred', name: '∈', args: [{k:'var',name:'x'}, {k:'var',name:'y'}] }
```

`∈` 在解析器里是中缀关系；`=`、`∈` 在显示时都输出为 `x = y` / `x ∈ y`。

## 公理

| 模块 | set.mm | 公式 | 身份 / 限制 |
| --- | --- | --- | --- |
| `axiom:ax-6` | ax-6 | `¬∀x¬x=y` | 等词存在公理 |
| `axiom:ax-7` | ax-7 | `x=y→(x=z→y=z)` | 等词替换 |
| `axiom:ax-8` | ax-8 | `x=y→(x∈z→y∈z)` | ∈ 左替换 |
| `axiom:ax-9` | ax-9 | `x=y→(z∈x→z∈y)` | ∈ 右替换 |
| `axiom:ax-12` | ax-12 | `x=y→(∀yP→∀x(x=y→P))` | 替换（当前版本无 DV） |
| `axiom:ax-13` | ax-13 | `¬x=y→(y=z→∀x y=z)` | 量化相等（当前版本无 DV） |

## 说明

- 等词章没有把 `equid`、`equcom`、`equtr` 等 set.mm 导出定理伪装成公理；关卡目标是 ax-6–ax-13
  本身及其安全的闭包/实例。`equid` 等定理需要更长的命题/量词推导，本作没有在游戏内重证。
- 闭包/例化的顺序必须与量词顺序对应：先内层后外层闭包，例化时先外层后内层。
- `ax-12`、`ax-13` 在当前 set.mm 里本身没有 distinct-variable 条件；`ax12v` / `ax13v` 才是带
  DV 的弱化版。游戏在注记中声明这一点。
- set.mm 的等词公理在类/集合论里还有 `ax-8`/`ax-9` 的 ∈ 版本；本游戏只用 setvar 原始语言，
  因此没有引入类抽象。
