# 公理审计：哪些是真公理，哪些应当变成关卡

原则：**只有推不出来的才保留为公理模块；能由更基本规则证明的，必须先做成关卡（`*NN`），之后只能以定理引用它。**

## 保留为基本公理/规则

| 模块 | 性质 | 说明 |
| --- | --- | --- |
| A1–A3 | 命题公理 | 希尔伯特系统的基本公理 |
| A4（∀E*） | 量词公理 | 全称例化 `∀x A → A[t/x]` |
| A5（∀dist） | 量词公理 | `∀x(A→B)→(∀xA→∀xB)` |
| shift（`∀*`） | 量词规则 | `A ⇒ A→∀xA`（x∉A），即 ax-5 形式 |
| eq-refl | 等词公理 | `t=t` |
| leibniz（=L） | 等词替换 | `x=y → (A→A[y/x])`，等词推理的基本原理 |
| ∃I / ∃E | 存在规则 | 存在推广/消去，是 ∃ 的定义性规则 |
| ∧I/∧E、∨I/∨E、↔I/↔E | 连接词定义规则 | 这些连接词是我们新增的语法构造，需要定义性规则 |
| 外延/空集/配对/并集 | 集合论公理 | 真正的集合论基本公理 |

## 应改为关卡（当前被当公理给出，但其可被证明）

| 模块 | 目标 | 计划 |
| --- | --- | --- |
| EXP | `((A∧B)→C)→(A→(B→C))` | 用 ∧I/∧E + A1/A2 做希尔伯特证明，做成关卡后删除模块 |
| IMP | `(A→(B→C))→((A∧B)→C)` | 用 ∧E + A2 证明，做成关卡后删除模块 |
| shift-ax（`∀→*`） | `∀x(A→B)→(A→∀xB)`（x∉A） | 由 A5 + shift + A1/A2 证明，做成关卡；`*73/*74` 改为引用该关 |

说明：EXP/IMP 目前没有被任何关卡引用（元件栏只显示参考证明用到的模块），所以移除它们不会破坏现有关卡；
shift-ax 被 `*73/*74` 使用，必须先做出对应定理关，再把这两关的参考证明改成 `*NN` 引用。

## 第二次审计（已完成 EXP/IMP，发现更多可证项）

已完成：`EXP`、`IMP` 已删除公理模块，改由关卡 `*15`（67 节点）与 `*20`（163 节点）证明，
证明只依赖 A1/A2 + `∧I*/∧E*`（作者侧用演绎定理生成）。

仍然“以公理/规则名义”给出、但其实可由更基本规则推出的：

| 模块 | 为什么可证 | 处理计划 |
| --- | --- | --- |
| `shift-ax`（∀→*） | 由 A5 + shift + A1/A2 可推出 | 做成关卡 `*66`，然后 `*73/*74` 改为 `*NN` |
| `all-elim`（规则） | 由 A4 公理 `∀xA→A[t/x]` + 分离直接得到 | 改用 A4 公理，删除重复规则 |
| `exists-intro`（规则） | 由 ∃I 公理 `A[t/x]→∃xA` + 分离得到 | 改用 ∃I 公理，删除重复规则 |
| `and-intro/and-elim`（规则） | 由 `∧I* / ∧E*` 公理形式 + 分离得到 | 改用公理形式，删除推理规则 |
| `or-intro/or-elim`（规则） | 由 `∨I* / ∨E*` 公理形式 + 分离得到 | 同上 |
| `iff-intro/iff-elim`（规则） | 由 `↔I* / ↔E*` 公理形式 + 分离得到 | 同上 |

可进一步减少的基础（设计取舍，暂不做）：
- 把 `↔` 定义为 `(A→B)∧(B→A)`，则 `↔I/↔E` 全部变成定理；
- 把 `∧` 定义为 `¬(A→¬B)`、`∨` 定义为 `¬A→B`，则全部连接词规则都可由 A1–A3 + 定义展开得到。
  这会改变公式的规范形式与显示方式，属于更大的重构，需要单独确认。

真正保留的基本公理/规则：A1–A3、A4、A5、shift（ax-5 形式）、等词自反、Leibniz、∃E、集合论公理。
